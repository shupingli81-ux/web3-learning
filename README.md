# web3-learning

My Web3 development journey - learning Solidity, DApp development, and the Ethereum ecosystem.

## Getting Started

```bash
# Install dependencies
npm install

# Start local node
npx hardhat node

# Deploy contracts
npx hardhat run scripts/deploy.js --network localhost
```
